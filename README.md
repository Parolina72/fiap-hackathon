# Trilha+ Front-end Web

Projeto convertido de Expo/React Native para React + TypeScript + Vite.

## Tecnologias
- React 19
- TypeScript
- Vite
- React Router DOM
- CSS

## Rotas
- `/` Home
- `/login` Login
- `/register` Cadastro
- `/explore` Explore

## Instalação
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

A lógica de autenticação/API ainda está representada pelos mesmos pontos de extensão do projeto original (por exemplo, o submit do login). Dependências específicas do Expo/React Native foram removidas da camada web.
